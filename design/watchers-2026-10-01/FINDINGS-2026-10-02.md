## Scope and source

- **Confirmed:** the fresh branch starts from current remote main. The unrelated
  primary checkout was not staged, cleaned, built or used as implementation source.

  privacy check.

## Contract decisions verified during implementation

- **Confirmed:** the package remains dependency-free and requires Python 3.11 or
  later. Python 3.9 supplied by some Xcode installations is not a supported test
  interpreter (`tomllib` and detached-runner `-P` require the project baseline).
- **Confirmed:** agent runs already provide durable run records, tool steps and
  multi-turn Pi continuation. `watcher-builder-v1` reuses that path and enables
  normal Pi discovery with an explicit feature charter. Scheduled script workers
  use their own detached execution path so companion restarts do not cancel them.
- **Confirmed:** the machine CLI credential resolver is `control_cli.machine_client`.
  The new CLI retains `--machine` rather than consuming it through the generic
  command wrapper, preventing a remote request from accidentally using the local
  token. All saved definitions are stamped with their owning machine.
- **Confirmed:** companion CLI wrappers are installed beside its interpreter.
  Integrated agents put that bin directory on PATH, while script steps receive
  their separate configured PATH and no Herdr control credentials.
- **Implemented:** raw chip markup is preserved alongside safe display tokens,
  plain text and validation warnings. Script/agent/skill/Slack chips must match
  actual step values. Chips and step icons label behavior; they do not execute
  instructions or grant permission.
- **Implemented:** definition and script bodies may be saved atomically in one
  create or revision-checked PATCH. This avoids a preview or scheduled revision
  seeing half of an editor's update.
- **Important limit:** main-token agents could technically call the activation
  endpoint. `confirmed_by: user`, UI activation and discovery guidance create an
  audit convention, not a scoped authorization boundary. The builder explicitly
  asks the person to review and activate.
- **Important limit:** dry run suppresses Watcher delivery and gate commits, but
  arbitrary script bodies can still have external effects. Cronboard migration
  preview only parses, validates and calculates times. It never uses dry-run
  execution to establish parity.
- **Compatibility:** exit 75 retains the requested Nothing new meaning even though
  the conventional `EX_TEMPFAIL` means a temporary failure. Imported routines must
  be reviewed with that behavior in mind.
- **Retention clarification:** retain the union of the newest 200 runs and the
  last 30 days, then prune older logs. This follows the plan's explicit
  “whichever is larger” rule; inbox items expire after 90 days.

Verification results are recorded in the delivery PR for its exact head.

## Review corrections

- **Implemented:** editing a watcher with the builder now uses a staged draft.
  Applying it checks the original revision and replaces that watcher's definition
  and scripts atomically, retaining history and source. It cannot silently leave
  two active schedules behind.
- **Implemented:** script filenames and step IDs reject case-insensitive
  collisions on macOS. The revision metadata filename is reserved.
- **Implemented:** detached workers record OS process birth identity before later
  signaling a persisted PID. Script processes retain the run lock if their runner
  disappears, preventing overlap during recovery. PID reuse is not treated as
  proof that a process belongs to a run.
- **Confirmed locally:** the focused schedule, definition, store, runner, API,
  import, CLI and builder checks use synthetic data. Native compilation succeeded;
  the final exact-head verification remains the delivery gate.
- **Implemented:** a creator's timezone travels into a remote builder session.
  Partial CLI edits leave an existing watcher's timezone untouched unless the
  person explicitly changes it.
- **Verified visually:** native views render at one, two and three columns with
  the approved Original avatar drawings, glass backgrounds and chip punctuation.
  SVG alpha colors are exported as explicit opacity attributes for the native
  asset compiler.
