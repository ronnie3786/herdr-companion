# Mac Dashboard and Agent view are retired

[Home and the four-tab Mac shell](macos-home.md) replace the Mac Dashboard, Agent view,
and standalone Activity destination. That guide covers current navigation, local actions,
the lead conversation tray, retained tools, compatibility, and verification.

The [companion summary and board APIs](dashboard-api.md) remain compatible. This Mac
presentation retirement does not remove server endpoints or the iOS Activity screens.
