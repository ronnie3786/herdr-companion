# Companion 0.67.2 beta 1

First Mate lists and conversations now remain readable when live verification
is slow or another refresh is checking the same feature. Display verification
has a shared three-second budget and competing reads return immediately with
verification marked unavailable. Retained assessments remain historical;
workflow gates still perform full verification.

Install this companion package on each affected host and restart its companion
service. Existing Mac, iOS, web, and Pi API contracts remain compatible. No Mac
app update or configuration/schema migration is required. Open First Mate and
refresh All Machines, then open a conversation with a long work history.
