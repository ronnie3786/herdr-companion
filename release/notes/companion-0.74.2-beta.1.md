# Companion 0.74.2 preview

Agent Roles reports missing execution copies by role and skill ID, allowing Mac 0.85.0 to distinguish copies that need updating from local folder-access issues. Existing API fields and clients remain compatible.

This release includes the storage-error reporting and human-wait handling from 0.74.1. Saved roles, prompts, selections, and immutable skill packages keep their existing format.

Install this companion package separately on execution computers using the normal backup, verification, and service-upgrade procedure. The Mac app updater does not update companion services. Strict role skill selection continues to require Pi 0.87.1 or newer.
