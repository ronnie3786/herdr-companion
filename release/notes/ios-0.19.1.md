# Herdr iOS 0.19.1 (52)

- First Mate Overview and Workflow show all active workers, queued directions and agents, and recorded authorized next stages.
- Pending directions remain visible independently of the conversation page. Completed workers no longer hide a newer active crew, and retained workers stay visible when they move between workflow steps.
- First Mate status reads allow 90 seconds. Larger request budgets also give loaded companions more time to answer health, terminal, and agent status checks.

Open a Second Mate feature on iPhone or iPad and check Overview or Workflow while agents are working and a follow-up is queued. The activity panel separates active work, queued work, and recorded next stages. New direction may change the recorded stages; plans mentioned only in conversation are not represented as execution queue entries.

Install companion 0.78.0b1 separately on each execution machine for independent queue previews, compact status responses, and longer peer deadlines. Older companions remain compatible but cannot provide every queue detail. This iOS build does not install the Mac app or companion server.
