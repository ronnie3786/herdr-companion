# Herdr for iPhone and iPad 0.19.2 (53)

First Mate now shows **Transcription details** when voice transcription fails. Open it and choose **Copy diagnostics** to share which steps failed, HTTP or native error codes, the app build, OS version, and attempt time. Private transcription and Apple Speech failures are both preserved. The report excludes recordings, transcripts, credentials, private server addresses, and raw server messages.

Apple Speech now distinguishes unsupported hardware from unsupported languages, permission failures, model downloads, and recognition errors. Failed quick recordings no longer claim they are retained; record again to retry. This release adds diagnostics and does not change provider selection or install companion server updates.
