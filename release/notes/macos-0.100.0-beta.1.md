# macOS 0.100.0-beta.1

Preview channel, build 152.

## Purple glass in Settings and feedback

Settings’ top bar and the **Report a Bug or Request a Feature** sheet now share First Mate’s purple Glass and Haze instead of grey system bars. Turning Glass off or enabling Reduce Transparency keeps both surfaces opaque. Addresses [#182](https://github.com/ronnie3786/herdr-companion/issues/182) in [PR #184](https://github.com/ronnie3786/herdr-companion/pull/184).

## Companion compatibility

No companion update is needed. This release updates the Mac app only. The companion server, CLI and Pi package are published separately and are not installed by the Mac updater.

## Install and verify

Enable preview builds, then choose **Settings → Updates → Check for Updates…** to install **0.100.0-beta.1 (build 152)**. With Glass enabled, confirm that Settings’ top bar and the feedback sheet use the same purple glass as First Mate. Turn Glass off, then separately enable Reduce Transparency, and confirm both surfaces stay opaque.
