# Herdr Companion 0.100.1-beta.1

- Main Chat can open with its completed skim already prepared. Install companion 0.82.1-beta.1 separately on each host to enable background preparation. Existing hosts remain compatible and continue preparing missing skims when a chat opens.
- First Mate retains the latest user direction across stage checkpoints, and large transcript records preserve available usage evidence. These fixes require the matching companion package.
- Includes the Settings window and issue-reporting appearance updates from the latest source.

The Mac update installs the app only. It does not restart companion servers or interrupt their running tasks. Use **Herdr Companion → Check for Updates…** to install the signed preview.
