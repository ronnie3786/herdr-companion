# First Mate Home

Herdr now opens on a native Home screen with four persistent tabs: Home, PR Review, Watchers, and Chats.

- See current work, the next item needing your attention, waiting conversations, watcher notices, and a linked activity recap. Loading, stale, and disconnected sources remain explicit.
- Open any item on its exact machine. Review requests keep their host selection and open the existing preparation form.
- Skip a focus item, snooze it for an hour with Undo, or dismiss a local observation. Fresh evidence brings an item back, and local hiding never clears the underlying work counts.
- Use verified quick replies when the current conversation supplies them. Otherwise, open the conversation to respond.
- Ask the existing lead First Mate in a compact tray, including context from a Home card. Suggestions fill a draft. Text, uploaded attachments, and context transfer once when you choose Open in First Mate.

Use Command-1 through Command-4 for the four tabs, Command-J to ask First Mate, and Command-F to search the current surface. Escape closes Home search before closing the tray. The First Mate window is always available. Fleet, First Mate management, Work inbox, Ask Agent, Settings, Notes, HUD, and Herd Pulse remain in Chats tools.

Home replaces the Mac Dashboard, Agent View, and separate Activity screen. Existing navigation history migrates to Home. First Mate builds, PR Review tools, chat and terminal controls, notifications, and alert history remain available.

This update installs only the Mac app. It uses existing companion capabilities and requires no server cutover. Older or unavailable capabilities show their limits; the iOS app and server contracts remain compatible. Home drafts survive tray dismissal and tab changes within the running app, but are not promised across app relaunches.
