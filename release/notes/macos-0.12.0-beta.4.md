# First Mate starts in dark mode

First Mate now opens in dark mode by default, matching the rest of the Mac app.
The appearance toggle remains available when you want light mode.

This update contains only the First Mate appearance default and release metadata.
It does not include the separate chat HUD changes under development.

Model and thinking-effort controls require companion 0.12.0b3 or later, unchanged
from Preview 3. The Mac updater does not install the companion server.

To test: relaunch the updated app and open First Mate. The workspace, chat,
inspector, and model picker should start in dark appearance.
