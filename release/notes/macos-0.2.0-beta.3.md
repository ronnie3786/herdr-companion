# Herdr 0.2.0-beta.3

The HUD's X button is now 20 points across, up from 16 points in the previous
preview, making it easier to see. Its position and pointer target are unchanged.

Enable **Include preview builds** in **Settings → App updates**, then choose
**Herdr → Check for Updates…**. After installing and relaunching, show the HUD
to see the larger X button.

This Mac-only update requires no companion server update. Existing machine
connections and credentials remain local.
