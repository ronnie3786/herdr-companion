# macOS 0.24.0-beta.1

## Project folders in the left nav are easier to read

The project folders in the sidebar are now easier to see ([#8](https://github.com/ronnie3786/herdr-companion/issues/8), [#10](https://github.com/ronnie3786/herdr-companion/pull/10)):

- Project folder names are larger and brighter, and folder icons are clearer.
- Folder rows have more room while chat rows stay compact.
- The sidebar follows your existing text-size setting, so no extra setup is needed.

## Compatibility

This release updates the Mac app only. The companion server, CLI, and Pi package are published separately, so install companion updates when you choose to. This change requires no server update and the shared API contract is unchanged.

## Install and verify

1. In **Settings → Updates**, turn on **Include preview builds** if it is off.
2. Choose **Herdr Companion → Check for Updates…**, review the update, and let Sparkle install and relaunch the app.
3. Expand a project in the left nav and confirm the folder names are larger and easier to read while chat rows remain compact. Change the text size in Settings and confirm the sidebar names follow it.
