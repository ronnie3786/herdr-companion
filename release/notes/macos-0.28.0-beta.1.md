# Herdr Companion 0.28.0 Preview 1

First Mate now renders formatted replies and retained markdown documents on Mac, including headings, lists, links, emphasis, and code blocks. Text remains selectable and follows First Mate's light or dark appearance and the app's text size settings.

The matching companion update keeps First Mate focused on brief coordination. Substantial planning, investigation, implementation, and review belong in tracked agent conversations, with detailed results in Agents and Documents.

## Compatibility and update

The markdown improvement works with existing companions supporting `first-mate-v1`. The coordinator behavior and browser markdown improvements require companion **0.28.0b1**, published separately as [Companion 0.28.0 Preview 1](https://github.com/ronnie3786/herdr-companion/releases/tag/companion-v0.28.0-beta.1). The signed Mac updater does not install or restart the companion server.

Choose **Herdr Companion → Check for Updates…**, install this preview, and open **First Mate**. Existing assistant messages render as markdown. After updating the companion separately, send your next direction in an existing or new feature; First Mate should acknowledge briefly and place substantial work in **Agents**. Full worker results remain available in **Documents** and saved sessions.
