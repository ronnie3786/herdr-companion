# Herdr Companion 0.28.0 Preview 2

First Mate's machine picker now includes **All Machines**. View features grouped by their companion host, search across machines, and open a feature's chat while keeping the combined list visible. A host that cannot load its features shows its own status while other machines remain available.

Each feature stays attached to its own machine. Switching between hosts preserves conversation drafts, and creating a feature asks you to choose its host.

This preview also includes Preview 1's styled markdown replies and retained markdown documents, with selectable text, light and dark appearances, and the app's text size settings.

## Compatibility and update

The All Machines view uses the existing `first-mate-v1` API and requires no companion API update. For the brief coordinator behavior, tracked agent work, and browser markdown improvements, install the separately released [Companion 0.28.0 Preview 1](https://github.com/ronnie3786/herdr-companion/releases/tag/companion-v0.28.0-beta.1). The Mac updater does not install or restart the companion server.

Choose **Herdr Companion → Check for Updates…**, install this preview, then open **First Mate** and select **All Machines** in the machine picker. You can return to any individual machine from the same menu.
