# Herdr Companion 0.36.0-beta.1

First Mate's Agent Session sheet now reads like a chat: saved prompts appear as right-aligned bubbles, agent replies render Markdown, and text-only tool results expand on demand. The transcript remains read-only, with no input or live session controls. Model and usage information is available under Session details, and older messages can still be loaded in order.

Open First Mate → a feature → Overview or Agents → an agent or a saved session. The same sheet is used when following session history or opening an author from a document. Use the First Mate demo to explore with synthetic conversations.

This Mac-only update uses the existing First Mate saved-session API. No server package update or configuration change is required; a companion with First Mate support must already be installed. The updater does not install or restart the companion server.
