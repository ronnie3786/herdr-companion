# Herdr Companion 0.43.0-beta.1

Dashboard is the new Mac home screen, using Herdr’s existing purple palette.

- Scan active First Mates, PR Reviews, and recent chats together. Cards open the existing feature, review, or conversation.
- Turn on **Focus mode** to hide work that is not waiting for you. The setting is shared with Agent view and persists across launches.
- Open **Agent view** for horizontally scrolling First Mate columns with Chat, Overview, Agents, and Workflow tabs, saved sessions, independent drafts, and replies to the owning companion.
- Return home with **Navigate → Dashboard** (Shift-Command-D). Both new views support Back and Forward navigation.
- PR summaries distinguish pending drafts, re-review requests, approval, and unavailable or stale GitHub state. Only visible Agent columns poll full conversations while the app is active.

Install companion **0.43.0b1** separately for lightweight First Mate summaries and live cached PR review status. Older companions remain compatible with unavailable-data fallbacks. The Mac updater installs only the app.

This preview retains the previously released First Mate authorized-stage continuation and recovery fixes, plus the current main branch’s PR deleted-file presentation improvements.

This is an Apple Development-signed preview distributed through the signed updater. It is not notarized.
