# Herdr for Mac 0.5.1-beta.1

- Star or unstar a chat directly from the star button beside its title in the Chat header. The star fills when selected and uses the same saved state as the sidebar's Starred section.

Open a chat and click the star beside its title to try it. Click again to remove it from Starred.

No companion server upgrade or iOS update is required. This preview uses the existing API contract and signed Mac update feed.
