# Herdr Companion 0.51.0-beta.1

## A new look: Mono × Herdr

Herdr takes on the calm, dense look of MonoCode, keeping its lavender accent and
status colors.

- **One frame for every screen.** A 40pt title bar carries the current screen's
  title and actions: a chat's name, status and pane actions; the Dashboard's
  search and Focus mode; the Agent view's filters; First Mate's feature, ticket,
  status menu and Chat | Git. The sidebar is 260pt wide. Drag its edge to resize
  it, and hide it with the title-bar button or **View → Toggle Sidebar** (⌃⌘S).
- **Chat.** Replies read as open prose in a centered column, with calmer code
  blocks, tables and lists. The composer shows the context line on top. **+**
  holds Attach files and Paste code block, one pill sets the model and thinking
  level, and Send is a lavender square that turns into Stop while the agent works.
- **Dashboard and Agent view** use quieter cards, rows and tabs.
- **First Mate** replies drop their box and avatar and sit under a small First
  Mate label, with thumbs and copy underneath. The coordinator context and model
  controls live inside the composer. The inspector has underline tabs and
  lighter cards. The feature goal now renders as Markdown, and the purple accent
  bars on Pull requests and Builds are gone.
- **First Mate's light appearance** now covers the whole window, including the
  composer and title bar. The Git tab stays dark.
- **HUD, Settings, Git and the other screens** share the same type, spacing and
  controls. Small labels across the app read at 11pt instead of 10pt.

## Glass and Haze

The sidebar, the pane and the HUD let the desktop show softly through them. The
sidebar is 80% opaque, the pane 75% and the HUD 78%. A faint dusk band sits
behind the top of each chat. Turn either off in **Settings → General →
Appearance**. With Reduce Transparency on in System Settings, Herdr draws
opaque surfaces. With Increase Contrast on, rules and outlines get stronger and
the dimmest text brightens. First Mate's light appearance is always opaque.

## Compatibility and installation

Install this preview through **Herdr Companion → Check for Updates…**, with
**Include preview builds** enabled. The app is Apple Development-signed,
distributed through the signed update feed, and is not notarized.

This is a Mac app change only. It works with any companion version and needs no
server, Pi, or iOS update.

## Check the changes

- Open a chat, the Dashboard, the Agent view and First Mate. Each shows its
  title and actions in the title bar.
- Put a colorful desktop picture behind the window to see the glass. Toggle
  **Glass** and **Haze behind the chat** in **Settings → General → Appearance**.
- In First Mate, switch to light with the sun button in the sidebar footer.
- Set **Settings → General → Text size** to 160% and check that the bars and
  cards still fit.
