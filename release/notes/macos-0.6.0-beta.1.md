# Herdr for Mac 0.6.0-beta.1

This preview brings the Comfortable reading design across the Mac app.

- Charcoal surfaces, lavender actions, softer dividers, and readable secondary
  text now extend through the sidebar, settings, workspace views, HUD, menu bar,
  Git, and Active Work.
- Conversations use larger system text, more space between paragraphs and turns,
  a bounded reading width, and quieter activity cards. Code remains monospaced,
  and the app's text-size preference still applies.
- The prompt has a unified input with Attach and More in its footer. Model and
  effort controls stay above it. Open More for voice and context tools, and expand
  Terminal keys when needed. Recording and playback states remain visible.
- Sidebar rows have more breathing room, a softer selection, and less idle status
  text. Starred chats, unread counts, and active status indicators remain available.

To try it, open a Pi conversation, expand an activity card, attach a file, and
open More. Check the HUD and Settings for the matching styles. Increase text size
in Settings to check the reading layout at your preferred scale.

This update requires macOS 26 or later. It uses the existing companion API and
requires no server, Pi extension, or iPhone app update. Existing feature-specific
server requirements still apply.
