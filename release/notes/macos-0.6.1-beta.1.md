# Herdr for Mac 0.6.1-beta.1

This preview refines the Comfortable reading design with Quiet chrome controls.

- The prompt keeps labeled Attach, Paste code, and Voice actions within reach.
  More holds additional context tools. Terminal keys now sit above the input,
  beside the compact model and reasoning controls.
- Chat turns use the full reading gutter without decorative rails or dots.
  Working sections and streamed text use tighter, consistent spacing.
- The sidebar has quieter outline icons, compact creation actions, and separators
  between machines instead of projects. The top navigation uses a compact segment
  strip.
- The HUD uses matching prompt controls. Text-size scaling, keyboard shortcuts,
  attachments, and recording controls remain available.

To try the changes, open a Pi chat, use Paste code, expand Terminal keys, and
switch sections with the top navigation. Watch a streamed response with activity
cards, and compare the sidebar's project and machine grouping.

This update requires macOS 26 or later. It uses the existing companion API and
requires no server, Pi extension, or iPhone app update. Existing feature-specific
server requirements still apply.
