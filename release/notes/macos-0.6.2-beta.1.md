# Herdr for Mac 0.6.2-beta.1

Recents now makes each chat easier to identify without adding extra rows of chrome.

- Chat titles use regular weight, align to the leading edge, and can wrap to two lines.
- One small, muted subtitle shows the computer icon, machine, workspace, and tab.
- Hover over a chat for its full context and last activity. Right-click a recent
  chat to open its workspace. Stars, unread indicators, selection, and recent
  activity ordering remain available.

To try it, choose Recents from the clock menu at the top of the sidebar.

Requires macOS 26 or later. This update uses the existing companion API and
requires no server, Pi extension, or iPhone app update.
