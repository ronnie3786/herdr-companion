# Herdr for Mac 0.6.4 beta 1

- Choose a thinking level beside the model, directly above the floating HUD prompt. The selection stays in sync with HUD Settings and applies to your next prompt or thread reply.
- Simplified the HUD chat header by removing New note and Ask. New chat and Collapse remain; notes are still available from the note stack and File → New Note.

## Try it

Open the HUD with Control-Option-Space, choose a thinking level above the prompt, and send a message. Change the level before replying to the same thread to use the new setting on the next turn.

## Compatibility

Mac-only update. No companion server, Pi extension, or iPhone update is required. Existing model availability and reasoning support depend on the configured provider. This preview uses development signing and is not notarized.
