# macOS 0.64.1-beta.1

The archive reason menu now includes **Completed** for features finished end-to-end. Choose **Archive feature… → Completed → Archive** to remove the feature from the active list while retaining its history. Other archive reasons remain available. Choosing a reason records why you archived the feature; it does not change workflow status or stop running work.

Completed requires companion **0.64.1b1** or newer, published separately. Install that companion package before using the new reason. Existing reasons continue to work with older companions. The Mac updater installs only the app.

Install through **Settings → Updates → Check for Updates…** with previews enabled. This preview uses the existing Apple Development signature and signed update feed and is not notarized.
