# macOS 0.65.0-beta.1

## First Mate messages

Your prompt now appears in the conversation as soon as you send it, before First Mate's working indicator. If sending fails, a clear red error preserves the content for recovery. [Issue #93](https://github.com/ronnie3786/herdr-companion/issues/93) · [PR #106](https://github.com/ronnie3786/herdr-companion/pull/106)

## Chat sidebar

Subtle dividers separate conversations; titles can wrap to two lines without repetitive Pi or terminal markers. Status and useful machine/project details appear together below each title, adapting to narrow sidebars. [Issue #89](https://github.com/ronnie3786/herdr-companion/issues/89) · [PR #105](https://github.com/ronnie3786/herdr-companion/pull/105)

## Companion compatibility

No companion server update is required for these changes. This release updates the Mac app only; the companion server, CLI and Pi package are published separately.

## Install and verify

With previews enabled, install through **Settings → Updates → Check for Updates…**. Send a First Mate message and confirm it appears in chat before the working indicator. Check that the chat sidebar shows dividers and readable two-line titles and metadata at both wide and narrow widths.
