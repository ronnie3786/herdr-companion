# macOS 0.69.0-beta.1

## First Mate conversation titles and emoji

- In the First Mate chat window, right-click a conversation, its header, or its transcript, or click the header name, then choose **Rename** or **Change Emoji…**. A pop-up lets you edit the **Title** and **Emoji**; the Emoji section opens the macOS emoji picker. The title uses the same 24-character label shown in the HUD. [Issue #113](https://github.com/ronnie3786/herdr-companion/issues/113) · [PR #115](https://github.com/ronnie3786/herdr-companion/pull/115).

## Companion compatibility

This release updates the Mac app only. The next companion adds an additive `label_source` field; older companions keep working. The companion server, CLI, and Pi package are published separately and are not installed by the Mac updater.

## Install and verify

With preview updates enabled, install via **Settings → Updates → Check for Updates…**. In the First Mate chat window, open the pop-up from a conversation, header, or transcript; change its title and emoji, then confirm the updated title appears in the HUD.
