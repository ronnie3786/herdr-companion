# Herdr Companion 0.7.0-beta.1

## Chat, with context you control

- Select and copy your own HUD messages, just like agent replies.
- Select chat text or code, choose **Quote & comment…**, add a comment, and Save a quoted attachment for your next message. Hover the attachment to preview the excerpt and comment, or use **Preview quote** in its context menu. Saving never sends. HUD sent quotes also retain their previews in history.
- **New Pi chat** keeps the previous available conversation above the new one, with a quiet divider and a copyable closed-session ID. Expand older chapters or show earlier messages without leaving the chat. Local history survives relaunch and is kept separate from the new agent's context.

## Notes and the Mac app

- Notes now use readable ink-colored insertion cursors and title placeholders. Default title and body text are one point larger and still follow the text-size setting.
- Hover the note header icons briefly for descriptive tooltips, including while another app is active.
- The app is now **Herdr Companion**, including its new release bundle name. Bundle ID, saved connections, Keychain identity, URL schemes, and signed updates are unchanged. Existing installations may retain their on-disk filename during an update.

## Try it

Use **Herdr Companion → Check for Updates…** with preview builds enabled. In the HUD, select part of one of your messages; in the main chat, select a response or code excerpt and save a comment. Hover its new attachment chip, then send when ready. Use the pane actions menu's **New Pi chat** and scroll up to see the previous chapter and session ID.

This is a Mac-only update. No companion-server, Pi-extension, or iOS update is required. Quotes use existing Markdown file attachments and their normal limits. Main-chat sent attachments retain the existing transcript attachment-path presentation; unsent main-chat attachments follow the existing pane-switch lifecycle. Session chapters preserve only transcript content available while this Mac follows the chat, not context Pi already omitted or sessions changed while the app was away.

Experimental preview, signed for personal testing and not notarized. Normal macOS first-install approval may still be required; signed update verification remains enabled.
