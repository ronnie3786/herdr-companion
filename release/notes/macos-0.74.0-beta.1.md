# macOS 0.74.0-beta.1

The standalone First Mate chat window now softly reveals the desktop behind its
purple glass background using Apple’s native window material. Text, messages,
and controls retain their normal opacity.

**Settings → General → Appearance → Desktop transparency** turns this effect
on or off immediately and remembers your choice. It is enabled by default.
Turning it off keeps the opaque purple glass and haze styling. macOS Reduce
Transparency also disables the effect, and light appearance remains opaque.

This update changes only the Mac app and works with the existing companion API.
No companion server or iOS update is required.

With preview updates enabled, use **Settings → Updates → Check for Updates…**.
Open a First Mate chat in its standalone window, then toggle **Desktop
transparency** in Settings to compare the two appearances.
