# macOS 0.77.0-beta.1

## First Mate HUD

First Mate’s latest message now opens right beside its face instead of beyond the
row of feature orbs. Drag the HUD anywhere on screen—left, right, middle, up, or
down—and it stays where you drop it instead of jumping back.

[Issue #142](https://github.com/ronnie3786/herdr-companion/issues/142) ·
[PR #143](https://github.com/ronnie3786/herdr-companion/pull/143)

## Companion compatibility

This release updates the Mac app only. The companion server, CLI, and Pi package
are published separately; the Mac updater does not install them.

## Install and verify

With preview updates enabled, use **Settings → Updates → Check for Updates…**
and install **0.77.0-beta.1** (build **124**). Open First Mate’s latest message and
check that the HUD appears beside its face. Drag it in different directions and
confirm it stays where you drop it.
