# Herdr Companion 0.80.1-beta.1

The First Mate chat window now has a Git button beside the inspector tabs. Select a feature, open its inspector, and choose **Open Git in New Window** to inspect that feature's recommended checkout. The checkout picker remains available, and opening Git again for the same feature brings its existing window forward.

Existing checkout and commit pop-outs keep their pinned targets. The My First Mate overview has no feature-specific Git button.

This is a Mac app update. No companion server update or configuration change is needed beyond the existing First Mate Git support.

Resolves #144.
