# Herdr Companion 0.80.2-beta.1

The First Mate inspector's **Overview** no longer has a **Verification** section. Open any feature's inspector: **Current focus** now follows the usage card directly. This matches the iPhone and iPad inspector, which dropped the section in iOS 0.18.0 (47).

The companion still records, assesses and enforces gate verification exactly as before. Workflow gates and release checks are unchanged, and the browser `/first-mate/` Overview, `herdr-first-mate get` and managed `fm_status` still show the assessment.

This is a Mac app update. No companion server update or configuration change is needed, and it works with the current companion (0.72.1b1).
