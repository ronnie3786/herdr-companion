# Herdr Companion 0.81.0-beta.1

Long completed replies in main Chat now have the same linked skims as First Mate and HUD chats. Summaries have about 20% more room for useful detail, and the full reply stays one click away.

When an agent offers a concrete next step, the skim can show up to three short reply chips. Labels use title case, while clicking sends the original offered phrase. Hover a chip for a one-sentence explanation. Informational replies and completed work need no chips. Chips work in main Chat, First Mate's main screen and chat window, and HUD conversations; drafts, stale replies, unavailable connections, and repeated clicks are protected.

Install companion **0.73.0b1** separately on each connected machine to enable the new skim model prompt and main Chat API. The Mac updater installs only the app. Older companions remain compatible and keep their previous skim behavior; existing cached skims are retained. The iOS presentation is unchanged.

To try it, open a long completed reply in Chat or First Mate, switch between **Skim** and **Full reply**, and hover its dotted phrases. For a reply that proposes a next step, hover a suggested reply to see its meaning, then click to send that phrase in the current conversation. Existing drafts keep the chips disabled until the composer is clear.
