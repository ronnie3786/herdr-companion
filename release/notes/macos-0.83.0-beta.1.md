# macOS 0.83.0-beta.1

## PR reviews across all machines

PR Review's host menu now includes **All machines**, selected by default each
time PR Review opens. It lists reviews from every paired machine in one place,
with each review labelled by its machine. Select a specific machine to narrow
the list.

[Issue #150](https://github.com/ronnie3786/herdr-companion/issues/150) ·
[PR #158](https://github.com/ronnie3786/herdr-companion/pull/158)

## Companion compatibility

This release updates the Mac app only; no companion update is needed for this
feature. The companion server, CLI, and Pi package are published separately and
are not installed by the Mac updater.

## Install and verify

With preview updates enabled, use **Settings → Updates → Check for Updates…** and
install **0.83.0-beta.1** (build **132**). Open PR Review and confirm **All machines**
is selected, reviews from paired machines appear together, and each review shows
its machine label. Select a specific machine to check filtering, then close and
reopen PR Review to confirm **All machines** is selected again.
