# Herdr Companion 0.86.1-beta.1

- The standalone First Mate window's right inspector starts 50 points wider. Drag its left edge to resize it; the chosen width is remembered and used when sliding the inspector open and closed.
- Resizing the conversation list no longer leaves two full-height purple focus lines. Both dividers retain keyboard and VoiceOver resizing with a compact keyboard focus marker.

Open the standalone First Mate window, show the inspector with Command-I, and drag its left divider. Close and reopen it to check the saved width. Drag the conversation-list divider and switch away from and back to the window to check the focus-line fix.

This updates only the Mac app. It adds no companion API requirements and needs no companion server update.
