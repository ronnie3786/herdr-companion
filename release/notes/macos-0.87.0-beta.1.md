# Notes that feel part of the page

- The Mac note editor now sits directly on the note paper, with aligned title and body, quieter formatting controls, and no inner border, tinted panel, or divider.
- iOS 0.19.0 adds the same bold, italic, underline, and strikethrough controls in a full-page note editor. Both apps share the same inline typing patterns: `**bold**`, `*italic*`, `_italic_`, and `~~strikethrough~~`.
- Basic emphasis and links survive sync between Mac and iOS, while older font families, sizes, and colors adopt the note typography. iOS text uses semantic body styling.

Open a Mac HUD note, or open Notes on iPhone or iPad and tap Edit. Try typing a completed inline pattern, selecting text and applying underline, and undoing the change. Existing companion note sync remains compatible and needs no server update.
