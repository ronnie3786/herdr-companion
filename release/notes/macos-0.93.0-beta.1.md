# macOS 0.93.0-beta.1

Preview channel, build 143.

Long completed replies in Main Chat, First Mate, and HUD chats show linked skims and up to three suggested reply chips when the response offers a concrete next step. Chips also remain available in Full reply mode. Main Chat includes the same hover explanations and normal message-send behavior.

This update fixes the native skim cache so refreshed suggestions appear immediately. Companion 0.78.0b1 fixes ordinary offers such as “I can add a test if you want” being discarded and refreshes stale skims for the latest recent First Mate and HUD replies once. Informational answers and work already underway continue to show no suggested actions.

Install companion **0.78.0b1** separately on each connected host for these generation fixes. The signed Mac updater installs only the app. Older companions remain compatible, but do not gain the new generation and cache refresh behavior.

With preview builds enabled, choose **Settings → Updates → Check for Updates…**. In Main Chat, First Mate, or a HUD chat, use a completed reply of at least 80 words with a concrete offered next step. Expect a linked skim and suggested replies beneath it. Hover for the explanation and click to send the displayed option through that conversation. Drafts and unavailable destinations disable sending. Replies shorter than the configured skim threshold continue to appear in full.
