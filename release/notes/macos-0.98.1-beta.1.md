# macOS 0.98.1-beta.1

Preview channel, build 149.

## First Mate window spacing

In the standalone First Mate window, a feature chat's top bar now centers its avatar vertically. The title and status stack closely beside it on one left edge, instead of being pushed to the top and bottom of the bar.

Fixes [#179](https://github.com/ronnie3786/herdr-companion/issues/179), delivered in [PR #181](https://github.com/ronnie3786/herdr-companion/pull/181).

## Companion compatibility

This Mac-only fix needs no companion update. This release updates the Mac app only; the companion server, CLI and Pi package are published separately and are not installed by the Mac updater.

## Install and verify

With preview builds enabled, choose **Settings → Updates → Check for Updates…** and install **0.98.1-beta.1**. Open a feature chat in the standalone First Mate window and confirm that the avatar is vertically centered and the title and status are closely stacked beside it, sharing a left edge.
