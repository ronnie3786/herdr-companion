# macOS 0.99.1-beta.1

Preview channel, build 151.

## Standalone First Mate spacing

A feature chat's top bar in the standalone First Mate window now centers its avatar vertically. The title and status are stacked closely beside it on one left edge, instead of being pushed to the top and bottom of the bar. Fixes [#179](https://github.com/ronnie3786/herdr-companion/issues/179) in [PR #181](https://github.com/ronnie3786/herdr-companion/pull/181).

## Companion compatibility

This change is Mac-only; no companion update is needed. This release updates the Mac app only. The companion server, CLI and Pi package are published separately and are not installed by the Mac updater.

## Install and verify

Enable preview builds, then choose **Settings → Updates → Check for Updates…** to install **0.99.1-beta.1 (build 151)**. Open a feature chat in the standalone First Mate window and confirm that the avatar is vertically centered, with the title and status closely stacked and left-aligned beside it.
